# H/R Studios · Տնտեսական գործունեության վերլուծություն

Ուսումնական հարթակ **ՀԱՊՀ, ԻՏ-447** խմբի համար՝ «Տնտեսական գործունեության վերլուծություն» առարկայի բոլոր դասերը, դասախոսի նյութերը, տնային աշխատանքների լուծումները և անիմացիոն ներկայացումները մեկ տեղում։

**Հեղինակ՝** Հրաչյա Ասլանյան · **Դասախոս՝** Օ.Ա. Գալստյան · **Ստուդիա՝** H/R Studios

## Ինչ կա հարթակում
- **8 դաս**՝ յուրաքանչյուրում «Դասը պարզ լեզվով», բանաձևերի քարտեր, բառարան, դասախոսի սլայդներ (դիտում հենց կայքում), ֆայլեր և տնային աշխատանքի լուծում
- **Անիմացիոն ներկայացումներ** (Դաս 7, Դաս 8) «Տվյալների սրահով»՝ սեղմեք ցանկացած թվի վրա և տեսեք Excel-ի բանաձևը
- **Գրադարան**՝ դասախոսի բոլոր ֆայլերը՝ ֆիլտրերով և որոնմամբ
- Աշխատում է համակարգչում և հեռախոսում, առանց սերվերի

## Կառուցվածք
```
index.html            գլխավոր էջ
works.html            «Իմ աշխատանքները»՝ ներկայացումներ, դաշբորդներ, Excel
lesson-1…8.html       դասերի էջեր
t7/, t8/              ներկայացումներ (Թեմա 7, Թեմա 8–9)
files/                լուծված Excel ֆայլեր
materials/tN/         դասախոսի նյութեր (+ slides/ սլայդների նկարներ)
assets/               նկարներ, ֆոնային տեսանյութեր, H/R Studios լոգո-ինտրո (intro.mp4)
src/                  գեներատորի կոդ (Python)
```

## Հրապարակում GitHub Pages-ում
1. Ստեղծեք նոր repository և վերբեռնեք այս թղթապանակի ամբողջ պարունակությունը (`index.html`-ը պետք է լինի արմատում)։
2. **Settings → Pages → Source:** `Deploy from a branch`, **Branch:** `main` / `(root)` → Save։
3. Մի քանի րոպեից կայքը հասանելի կլինի `https://<username>.github.io/<repo>/` հասցեով։

## Թարմացում
Էջերը գեներացվում են `src/gen/gen.py`-ով (բովանդակությունը՝ `src/gen/content.py`)։ Նոր դաս ավելացնելու համար լրացրեք `content.py`-ը և գործարկեք `python3 src/gen/gen.py`։
